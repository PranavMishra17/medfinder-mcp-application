# medfinder-mcp-application

MCP agent for applying to Medfinder. Uses Claude to reason through screening questions based on your resume, projects, and profile.

## Setup
1. Copy `.env.example` to `.env` and fill in your details
2. Run `python medfinder_agent.py`

## What it does
Submits your application through the Medfinder MCP with personalized responses to screening questions.
